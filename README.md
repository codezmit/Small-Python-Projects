# Small Python Projects

This repository contains a few beginner-friendly Python mini-projects to practice logic, user input, and game development.

## Projects

### 1. Guess the Number
A simple number guessing game where the player tries to guess a random number between 1 and 100. The program gives hints like "Higher Number Please!" or "Lower Number Please!" until the correct guess is found.

- File: `Guess the Number/main.py`

### 2. Snake Water Gun Game
A classic hand game simulation of Snake, Water, and Gun against the computer. The user enters their move and the program compares it with the computer's random choice to decide the winner.

- File: `Snake_Water_Gun _Game/swg_game.py`

## How to Run

Open a terminal in the project folder and run a Python file, for example:

```bash
python "Guess the Number/main.py"
```

or

```bash
python "Snake_Water_Gun _Game/swg_game.py"
```

## Requirements

- Python 3 installed on your system

## Notes

These are small practice projects intended for learning Python basics such as:
- variables and conditionals
- loops
- random number generation
- user input
- simple game logic
